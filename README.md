# 🍓 The Happy Jam Jar 🍯

Welcome to **The Happy Jam Jar**! This is a cute, casual, and wholesome arcade game where your main goal is to collect as many sweet treats as possible. 

## 🎮 How to Play
* Move your mouse (or your finger on mobile) **left and right** to slide the Jam Jar across the screen.
* 🍓 **Catch the Strawberries** to earn **1 point** each!
* ❤️ **Catch the Hearts** to get a sweet bonus of **5 points**!

## 🛠️ Built With
* **Scratch** - For game logic, design, and animations.
* **TurboWarp** - Used to compile the Scratch project into a clean HTML webpage.
* **GitHub Pages** - For hosting and making the game playable right in the browser!
